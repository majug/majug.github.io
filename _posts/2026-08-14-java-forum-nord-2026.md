Am **22. September 2026** findet in Hannover wieder das
[Java Forum Nord](https://javaforumnord.de/2026/) statt.

Das Java Forum Nord ist eine von Java User Groups organisierte
Community-Konferenz mit einem umfangreichen Programm rund um Java,
Softwareentwicklung und Architektur. In diesem Jahr findet die
Konferenz erstmals an der **Medizinischen Hochschule Hannover (MHH)**
statt. Als Keynotes sind **Nora Schöner** und **Oliver Zeigermann**
angekündigt.

Wer Lust auf einen Tag mit Vorträgen, Austausch und Java-Community hat,
sollte einen Blick auf das Programm werfen.
